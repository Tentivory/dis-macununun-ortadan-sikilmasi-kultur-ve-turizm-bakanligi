# dis-macununun-ortadan-sikilmasi-kultur-ve-turizm-bakanligi
Diş macununun tüpünün ortadan sıkılmasını resmi kültür varlığı tahribatı, milli macun egemenliği ihlali ve turizm protokolü sapması sayan; kapağı müze müdürü, 'ben kenardan sıkarım' cümlesini sit alanı ihlali ilan eden Bakanlık. Gerçekten çalışır. Tüpler artık eserdir.
